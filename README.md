# Titanic Data Analysis

## Project Overview
This is a beginner-friendly Data Science mini project that analyzes the Titanic passenger dataset.

## Objective
To explore passenger data and understand survival patterns.

## Tools Used
- Python
- Pandas
- Matplotlib
- Google Colab

## Work Completed
- Loaded and explored the dataset.
- Checked missing values and dataset information.
- Counted survived and non-survived passengers.
- Created a bar chart to visualize survival counts.

## Conclusion
This project helped me practice Python, data analysis, and data visualization.
